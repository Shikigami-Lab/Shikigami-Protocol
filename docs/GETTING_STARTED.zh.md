## 最少几步能聊上天？

| 步骤 | 做什么 | 在哪里 |
|:---:|:---|:---|
| **1** | 配置至少**一个对话模型**（云端 Key 或本地 Base URL） | 设置 → **模型** |
| **2** | 至少有一张**人格卡**（可用 AI 向导从描述生成整张卡） | 设置 → **人格** |

完成 **1 + 2** 即可在主界面开始对话。

## 代理（大陆或受限网络）

> 大多数用户可跳过此节，仅在无法直连 Gemini / OpenAI 等云端 API 时才需要。

后端是 **Python 进程**，系统里「浏览器能翻墙」不等于 Python 已走代理。

**推荐做法**：

1. 打开 **设置 → 系统**。
2. 勾选 **使用代理**，填写：`http://127.0.0.1:端口`（端口见你的代理软件 HTTP / Mixed Port）。
3. **保存**后**重启**应用（使环境变量生效）。

若不确定端口：在代理软件界面查「本地 HTTP 端口」；或在 CMD 执行 `netstat -ano | findstr LISTENING` 找 `127.0.0.1` 上的常见端口（如 `7890`、`10808`）。

也可直接编辑 **`.env`** 设置 `HTTP_PROXY` / `HTTPS_PROXY`（与设置页效果一致）。

## 设置页各 Tab 一览

| Tab | 用途 |
|:---|:---|
| **入门** | **分步引导 (推荐)**：清单自检、网络、记忆/TTS/STT；陪伴行为（情绪/好感度等）仅指路，细则见本文下一节。 |
| **人格** | 角色卡列表、编辑、**AI 向导**生成卡、侧栏排序、记忆 / 引擎等人格级覆盖；**Prompt 编辑**子标签含人格演化 |
| **模型** | LLM 预设管理、API Key、本地 OpenAI 兼容地址、辅助模型（情感 / 好感等） |
| **记忆** | 长期事实、向量记忆开关、嵌入模型（云端 Gemini 或本地 BGE 等）、日记与遗忘预览 |
| **TTS** | 朗读引擎：Edge / GPT-SoVITS / Kokoro / Qwen3-TTS |
| **行为 / 自省** | 角色内心独白、主动发言配置 |
| **VLM** | 屏幕 / 视觉理解：模型与截图策略 |
| **工具** | 待办、计时器、天气、趋势、网页搜索等工具插件的开关与配置 |
| **系统** | 主题、代理、HF 镜像、离线开关 |

人格卡里还可配置情绪/能量/好感文案、记忆策略、TTS 参考音等——字段说明见 [profile_prompts.zh.md](./profile_prompts.zh.md)。

## 情绪、能量、好感度、自省与主动发言（ASE）

这些能力让角色不只是「接话」，而是有**当前情绪、精力、长期关系**，并可在后台**自省**、在你**长时间沉默时主动开口**。默认不必改文案也能用；若要更黏人、更克制或更像稳定工具人，再按下面调整。

### 情绪引擎

- **作用**：按对话内容更新情绪层，影响回复语气，并参与情绪化 TTS 的 instruct（若启用）。
- **去哪调**：`设置 → 人格 → 行为` 中开关**情绪引擎**；各情绪下的**说话规则**在人格编辑里与情绪相关的 Prompt 区（`emotion_prompts`、`emotion_zh_descriptions`）。字段含义见 [profile_prompts.zh.md](./profile_prompts.zh.md) 的 `emotion_config` 一节。
- **建议**：日常陪伴建议保持开启；若只当代码/工具问答、不希望语气起伏，可对该人格关闭。

### 能量系统

- **作用**：聊天会消耗精力，离线或隔一段时间会恢复；不同能量档位可对应「多说 / 少说 / 疲惫」等风格（由 `energy_prompts` 描述）。
- **去哪调**：全局默认在 `config/app.yaml` 的 `engines.energy`；每人格是否在对话里扣能量、是否注入能量文案，在 `设置 → 人格 → 行为` 的**能量**相关开关与覆盖；各档**行为指令**在人格的**能量 Prompt** 覆盖里填写（勿写剧情旁白，写「该怎么说话」的规则）。
- **建议**：不要把单句消耗设得过高、也不要把完全恢复时间拉得过长，否则容易出现「聊几句就完全不想说话」的体验。可先沿用默认，再微调。

### 好感度引擎

- **作用**：根据近期对话用辅助模型微调好感度数值，对应「陌生 → 熟悉 → 亲密」等阶梯；`affinity_prompts` 规定各阶梯下**距离感、措辞、禁止行为**等。
- **去哪调**：`设置 → 人格 → 行为` 开关**好感度引擎**；`设置 → 模型` 可配置用于情感/好感分析的辅助模型；人格侧好感文案在 **好感度 Prompt**（`affinity_prompts`），详见 [profile_prompts.zh.md](./profile_prompts.zh.md)。
- **建议**：需要长期关系感时开启；若以 RP 吵架、虚构冲突为主，系统规则上会把「戏谑/剧情」与真实敌意区分——若你希望某段剧情真的伤关系，需在设定或对话里明确表达。调整**单次最大变化**可控制好感波动幅度。

### 自省（Reflection）

- **作用**：后台周期性用单独 LLM 生成简短「内心状态」（如话题提示、风格提示），供主对话与 ASE 决策参考；**会持续消耗 token**。
- **去哪调**：`设置 → 行为 / 自省` 或 **自省 / ASE** Tab 中总开关与间隔；`设置 → 模型 → 自省模型` 指定专用或沿用主模型；每人格的 `reflection_config.custom_prompt` 等在 **人格 → 自省配置** 中编辑。
- **建议**：先配好**便宜或本地**自省模型再开；间隔不宜过短（常见 60～300 秒量级，具体见界面说明）。详细段落与触发方式与「Prompt 增强段落」体系一致，保存时注意按界面提示分别保存。

### 主动发言（ASE）

- **作用**：在满足沉默时长、紧迫度、冷却与每日上限等条件时，角色**主动发一条消息**打破沉默；可与趋势、天气、自省内容等结合。
- **去哪调**：`设置 → 行为` 或 **自省 / ASE** Tab 中 ASE 总开关与**模式**（低/中/高/游戏/专注等）；各模式对应检测间隔、最短沉默、紧迫度阈值、冷却与 24h 次数上限等在 `config/app.yaml` 的 `ase.modes` 中定义，部分可在 UI 覆盖。需要画面时配合 **VLM** 与「主动发言时截图」等选项。
- **建议**：人设与情绪稳定后再开 ASE，避免「话风未定型就频繁打扰」。觉得太吵：先换**低**模式或提高紧迫度阈值、拉长最短间隔，而不是立刻全关（除非你明确不想要主动消息）。

### 人格演化（Persona Evolution）

- **作用**：每 N 轮对话（与情绪/好感度引擎计数方式相同），AI 会根据积累的记忆事实与好感度阶段，对 `base_prompt` 和 `style_constraint` 做微小重构——让角色随相处经历自然成长，而非永远被钉死在初稿。
- **核心锚点**：你（或点「重新提炼」让 AI 自动提取）写下几条分号分隔的不可改变特质，如 `嘴硬心软；遇强则强；绝不主动承认在意`。每次重构时作为硬约束传入，防止角色越养越「客服化」。
- **去哪调**：`设置 → 人格 → Prompt 编辑`，在风格约束下方的**人格演化**折叠块：
  - **启用开关**（默认关闭）与 **触发间隔**（每 N 轮对话触发一次，默认 200 轮，与情绪/好感度引擎用同一计数器）。
  - **重新提炼**：让 AI 从当前人设自动提炼核心锚点，之后可手动微调。
  - **原始人格（只读）**：你写的初稿，永不参与演化，随时可对照查看。
  - **当前演化版本**：实际生效的人设，可直接手动编辑，自动保存。
  - **演化日志**：每次改动的摘要与理由，点**回滚**可还原到任意历史版本。
- **建议**：先让角色跑几轮对话积累记忆后再开启。如果你的人设精心雕琢、不希望 AI 自动改动，可关闭开关——锚点与日志仍可作参考。

## 可选增强

### 记忆与向量检索

- 使用 **Gemini 等云端嵌入**：在「模型」里配置 Key 即可，向量记忆走云端。
- 无云端 Key、想用**本地向量检索**：在「入门」页用 HF 镜像 / ModelScope 下载 BGE-small 等到 `models/`，再到「记忆」将嵌入提供方改为本地并填写路径。
- 设置了 `HF_HUB_OFFLINE=1` 时，在线下载会失败，需先关闭离线或自备模型。

### 语音输入（STT）

在「入门」页的 STT 区选择引擎并下载模型：
- **SenseVoice**（ONNX）：多语言、速度较快，适合多数场景。
- **Whisper / faster-whisper**：更重、更准，按需下载（可指定 `stt.model_path` 使用本地文件）。

### 语音朗读（TTS）

- **Edge TTS**：免装模型，需联网，100+ 音色。
- **Kokoro**：本地 ONNX，~200ms 延迟，支持 zh / ja / en。
- **GPT-SoVITS / Qwen3-TTS**：按「TTS」页说明安装依赖或下载权重。Qwen3-TTS 依赖 PyTorch，见下方。

### Qwen3-TTS 与 PyTorch（仅使用 Qwen3-TTS 时）

`requirements-ai.txt` 中不含 GPU 版 PyTorch（避免强制下载 GB 级文件）。需单独安装：

```bat
# NVIDIA GPU（CUDA，版本按显卡驱动调整）
.venv\Scripts\python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128

# 仅 CPU
.venv\Scripts\python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
```

更多组合见 [PyTorch 官网](https://pytorch.org/)。若报错 `Torch not compiled with CUDA enabled`，说明安装的是 CPU 版，按上方换 cu 版或在 TTS 设置里改设备为 `cpu`。

### 屏幕 / 视觉（VLM）

在「VLM」中配置多模态模型后，可在支持场景下使用截图理解能力（依赖所选 API 或本地多模态服务）。

### 环境感知工具（天气 / 趋势）

在「工具」页启用并配置天气、趋势（RSS / API）等工具；启用后会注入 prompt 并影响主动发言内容。
